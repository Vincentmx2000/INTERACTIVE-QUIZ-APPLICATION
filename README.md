# 🧠 Interactive Quiz Application

A fun, fully interactive web-based quiz app built with **HTML**, **CSS**, and **JavaScript** — featuring category selection, real-time feedback, score tracking, high score storage, and dark mode.

---

## 📌 Overview

This project started as a basic quiz and evolved into a polished, engaging experience. The goal was to build something lightweight yet enjoyable — where users can test their General Knowledge or Science skills in a clean, responsive interface.

---

## ✨ Features

- 📂 **Category Selection** — Choose from General Knowledge, Science, or All
- 🔀 **Randomized Answers** — Options shuffled every time for fairness
- ✅ **Instant Feedback** — Green for correct, red for wrong (with correct answer shown)
- 📊 **Progress Indicator** — "Question X of 10" displayed throughout
- 🏆 **High Score Tracker** — Best score saved locally via localStorage
- 📈 **Results Screen** — Final score, correct/incorrect breakdown, and percentage
- 🌙 **Dark Mode Toggle** — Seamless light/dark theme switch
- 📱 **Fully Responsive** — Works on desktop, tablet, and mobile

---

## 🛠️ Tech Stack

| Technology      | Purpose                                      |
|-----------------|----------------------------------------------|
| HTML5           | Structure and content                        |
| CSS3            | Styling, animations, responsiveness          |
| JavaScript      | Quiz logic, DOM manipulation, interactivity  |
| localStorage API| Persisting high score across sessions        |
